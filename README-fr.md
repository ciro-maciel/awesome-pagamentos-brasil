Pour ceux qui facturent au sein d'un système et doivent choisir comment. On commence par les normes de la Banque centrale et de la Febraban, on passe par les passerelles et les acquéreurs, et on finit par les bibliothèques ouvertes pour le boleto (bulletin de paiement bancaire). Chaque lien a été vérifié avant d'être ajouté.

## Normes

Ce que définissent le Banco Central et la Febraban.

- [Arranjos de pagamento](https://go.mymarketing.click/pagbr-arranjos-de-pagamento) - Les règles du Banco Central pour les cartes, les portefeuilles et les autres arrangements de paiement. `officiel` `gratuit`
- [Pix](https://go.mymarketing.click/pagbr-pix) - La page officielle du Pix sur le site du Banco Central. `officiel` `gratuit`
- [Pix Automático](https://go.mymarketing.click/pagbr-pix-automatico) - La modalité Pix pour les prélèvements récurrents, avec autorisation préalable du payeur. `officiel` `gratuit`
- [Nova Plataforma de Boletos](https://go.mymarketing.click/pagbr-nova-plataforma-de-boletos) - Le registre centralisé des boletos (boleto : titre de paiement bancaire) de la Febraban. `officiel` `gratuit`

## Étiquettes

Chaque entrée indique ce qu'elle est. Les étiquettes à côté aident à choisir : officiel quand l'outil vient de celui qui définit la norme, open source quand le code est publié, gratuit ou payant selon le modèle d'utilisation, API et SDK selon la manière de l'intégrer. Les entrées avec l'étiquette « de l'auteur » sont faites par Ciro Cesar Maciel et suivent les mêmes règles que toutes les autres.
