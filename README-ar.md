## القواعد

ما يحدده Banco Central وFebraban.

- [Arranjos de pagamento](https://go.mymarketing.click/pagbr-arranjos-de-pagamento) - قواعد Banco Central للبطاقات والمحافظ وترتيبات الدفع الأخرى. `رسمي` `مجاني`
- [Pix](https://go.mymarketing.click/pagbr-pix) - الصفحة الرسمية لـ Pix في Banco Central. `رسمي` `مجاني`
- [Pix Automático](https://go.mymarketing.click/pagbr-pix-automatico) - نوع من Pix للمدفوعات المتكررة، بإذن مسبق من الدافع. `رسمي` `مجاني`
- [Nova Plataforma de Boletos](https://go.mymarketing.click/pagbr-nova-plataforma-de-boletos) - السجل المركزي لبوليتو (boleto، وهو فاتورة دفع بنكية) التابع لـ Febraban. `رسمي` `مجاني`

## البوابات والمعالجات الفرعية

البطاقة والبوليتو وPix والاشتراكات في واجهة واحدة. مرتبة أبجديًا.

- [Adyen](https://go.mymarketing.click/pagbr-adyen) - منصة دفع عالمية، تشمل البطاقة وPix والبوليتو في البرازيل. `API` `مدفوع`
- [Asaas](https://go.mymarketing.click/pagbr-asaas) - تحصيل عبر Pix والبوليتو والبطاقة، مع الاشتراكات والتقسيم (split). `API` `مدفوع`
- [dLocal](https://go.mymarketing.click/pagbr-dlocal) - مدفوعات في الأسواق الناشئة، ومنها البرازيل. `API` `مدفوع`
- [EBANX](https://go.mymarketing.click/pagbr-ebanx) - مدفوعات محلية في أمريكا اللاتينية، للشركات داخل البرازيل وخارجها. `API` `مدفوع`
- [Efí](https://go.mymarketing.click/pagbr-efi) - الاسم السابق Gerencianet: Pix والبوليتو والبطاقة وcarnê عبر API. `API` `مدفوع`
- [Iugu](https://go.mymarketing.click/pagbr-iugu) - تحصيل واشتراكات وتقسيم (split) مع Pix والبوليتو والبطاقة. `API` `مدفوع`
- [Mercado Pago](https://go.mymarketing.click/pagbr-mercado-pago) - صفحة الدفع وPix والبطاقة والبوليتو والاشتراكات من Mercado Pago. `API` `مدفوع`
- [Pagar.me](https://go.mymarketing.click/pagbr-pagar-me) - مدفوعات عبر Pix والبطاقة والبوليتو، مع التكرار والتقسيم. `API` `مدفوع`
- [PagBank](https://go.mymarketing.click/pagbr-pagbank) - الطلبات والتحصيل عبر Pix والبطاقة والبوليتو. `API` `مدفوع`
- [Stripe](https://go.mymarketing.click/pagbr-stripe) - البوليتو وPix والبطاقة عبر Stripe، مع التحصيل المتكرر بـ Stripe Billing. `API` `مدفوع`
- [Vindi](https://go.mymarketing.click/pagbr-vindi) - API للتحصيل المتكرر والاشتراكات. `API` `مدفوع`
- [Zoop](https://go.mymarketing.click/pagbr-zoop) - بنية تحتية للمدفوعات للأسواق الإلكترونية والمنصات، مع التقسيم. `API` `مدفوع`
