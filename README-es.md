## Normas

Lo que definen el Banco Central y la Febraban.

- [Arranjos de pagamento](https://go.mymarketing.click/pagbr-arranjos-de-pagamento) - Las reglas del Banco Central para tarjetas, billeteras y otros arreglos de pago. `oficial` `gratis`
- [Pix](https://go.mymarketing.click/pagbr-pix) - La página oficial del Pix en el Banco Central. `oficial` `gratis`
- [Pix Automático](https://go.mymarketing.click/pagbr-pix-automatico) - La modalidad de Pix para cobros recurrentes, con autorización previa del pagador. `oficial` `gratis`
- [Nova Plataforma de Boletos](https://go.mymarketing.click/pagbr-nova-plataforma-de-boletos) - El registro centralizado de boletos (fichas de pago bancario) de la Febraban. `oficial` `gratis`

## Gateways y subadquirentes

Tarjeta, boleto (ficha de pago bancario), Pix y suscripción en una sola API. En orden alfabético.

- [Adyen](https://go.mymarketing.click/pagbr-adyen) - Plataforma global de pagos, con tarjeta, Pix y boleto en Brasil. `API` `de pago`
- [Asaas](https://go.mymarketing.click/pagbr-asaas) - Cobros por Pix, boleto y tarjeta, con suscripciones y split. `API` `de pago`
- [dLocal](https://go.mymarketing.click/pagbr-dlocal) - Pagos en mercados emergentes, incluido Brasil. `API` `de pago`
- [EBANX](https://go.mymarketing.click/pagbr-ebanx) - Pagos locales en América Latina, para empresas de dentro y fuera de Brasil. `API` `de pago`
- [Efí](https://go.mymarketing.click/pagbr-efi) - Antes Gerencianet: Pix, boleto, tarjeta y carnê por API. `API` `de pago`
- [Iugu](https://go.mymarketing.click/pagbr-iugu) - Cobros, suscripciones y split con Pix, boleto y tarjeta. `API` `de pago`
- [Mercado Pago](https://go.mymarketing.click/pagbr-mercado-pago) - Checkout, Pix, tarjeta, boleto y suscripciones de Mercado Pago. `API` `de pago`
- [Pagar.me](https://go.mymarketing.click/pagbr-pagar-me) - Pagos por Pix, tarjeta y boleto, con recurrencia y split. `API` `de pago`
- [PagBank](https://go.mymarketing.click/pagbr-pagbank) - Pedidos y cobros por Pix, tarjeta y boleto. `API` `de pago`
- [Stripe](https://go.mymarketing.click/pagbr-stripe) - Boleto, Pix y tarjeta en Stripe, con cobro recurrente mediante Stripe Billing. `API` `de pago`
- [Vindi](https://go.mymarketing.click/pagbr-vindi) - API de cobro recurrente y suscripciones. `API` `de pago`
- [Zoop](https://go.mymarketing.click/pagbr-zoop) - Infraestructura de pagos para marketplaces y plataformas, con split. `API` `de pago`

## Adquirentes

Quien procesa la tarjeta. En orden alfabético.

- [Cielo](https://go.mymarketing.click/pagbr-cielo) - La documentación para desarrolladores de Cielo: e-commerce, link de pago y terminal. `API` `de pago`
- [Getnet](https://go.mymarketing.click/pagbr-getnet) - El portal para desarrolladores de Getnet. `API` `de pago`
- [Rede](https://go.mymarketing.click/pagbr-rede) - El portal para desarrolladores de Rede, de Itaú. `API` `de pago`
- [Stone](https://go.mymarketing.click/pagbr-stone) - La documentación de Stone para pagos y cuenta. `API` `de pago`

- [BoletoNetCore](https://go.mymarketing.click/pagbr-boletonetcore) - La versión de Boleto.Net para .NET Core. `código abierto` `gratis`
- [BoletoPHP](https://go.mymarketing.click/pagbr-boletophp) - Sistema de boletos bancarios en PHP, de código abierto. `código abierto` `gratis`
- [brcobranca](https://go.mymarketing.click/pagbr-brcobranca) - Boletos y archivos de remesa y retorno en Ruby. `código abierto` `gratis`
- [laravel-boleto](https://go.mymarketing.click/pagbr-laravel-boleto) - Boletos, remesas y retornos en PHP, para varios bancos. `código abierto` `gratis`
- [OpenBoleto](https://go.mymarketing.click/pagbr-openboleto) - Generación de boletos bancarios en PHP (boleto bancario). `código abierto` `gratis`

## Etiquetas

Cada ítem dice qué es. Las etiquetas al lado ayudan a elegir: oficial cuando viene de quien define el estándar, código abierto cuando el código está publicado, gratis o de pago según el modelo de uso, API y SDK según la forma de integrar. Los ítems con la etiqueta "del autor" son hechos por Ciro Cesar Maciel y siguen las mismas reglas que todos los demás.
