## boleto 和 CNAB 库

无需依赖网关即可生成 boleto 和回款文件。开源。

- [boleto.js](https://go.mymarketing.click/pagbr-boleto-js) - 用 JavaScript 将 boleto 的条形码渲染为 SVG。 `开源` `免费`
- [Boleto.Net](https://go.mymarketing.click/pagbr-boleto-net) - 适用于 .NET 的巴西银行 boleto 库。 `开源` `免费`
- [BoletoNetCore](https://go.mymarketing.click/pagbr-boletonetcore) - 适用于 .NET Core 的 Boleto.Net 版本。 `开源` `免费`
- [BoletoPHP](https://go.mymarketing.click/pagbr-boletophp) - PHP 开源银行 boleto 系统。 `开源` `免费`
- [brcobranca](https://go.mymarketing.click/pagbr-brcobranca) - Ruby 下的 boleto 及 remessa、retorno 文件。 `开源` `免费`
- [laravel-boleto](https://go.mymarketing.click/pagbr-laravel-boleto) - PHP 中的 boleto、remessa 和 retorno，支持多家银行。 `开源` `免费`
- [OpenBoleto](https://go.mymarketing.click/pagbr-openboleto) - 使用 PHP 生成银行票据（boleto，巴西银行转账单）。 `开源` `免费`
