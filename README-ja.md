## 規範

ブラジル中央銀行とFebrabanが定めるもの。

- [Arranjos de pagamento](https://go.mymarketing.click/pagbr-arranjos-de-pagamento) - カード、電子財布、その他の決済スキームに関するブラジル中央銀行の規則。 `公式` `無料`
- [Pix](https://go.mymarketing.click/pagbr-pix) - ブラジル中央銀行のPix公式ページ。 `公式` `無料`
- [Pix Automático](https://go.mymarketing.click/pagbr-pix-automatico) - 事前に支払人の承認を得る、定期請求向けのPixの方式。 `公式` `無料`
- [Nova Plataforma de Boletos](https://go.mymarketing.click/pagbr-nova-plataforma-de-boletos) - Febrabanによるボレト（銀行払込票）の集中登録。 `公式` `無料`

カード、ボレト、Pix、サブスクリプションをひとつのAPIで。アルファベット順。

- [Asaas](https://go.mymarketing.click/pagbr-asaas) - Pix、ボレト、カードによる請求。サブスクリプションとスプリット付き。 `API` `有料`
- [dLocal](https://go.mymarketing.click/pagbr-dlocal) - 新興市場での決済。ブラジルを含む。 `API` `有料`
- [EBANX](https://go.mymarketing.click/pagbr-ebanx) - ラテンアメリカでの現地決済。ブラジル国内外の企業向け。 `API` `有料`

- [Pagar.me](https://go.mymarketing.click/pagbr-pagar-me) - Pix、カード、ボレトによる決済。定期課金とスプリット付き。 `API` `有料`
- [PagBank](https://go.mymarketing.click/pagbr-pagbank) - Pix、カード、ボレトによる注文と請求。 `API` `有料`
- [Stripe](https://go.mymarketing.click/pagbr-stripe) - StripeでのボレトとPix、カード。Stripe Billingによる定期請求付き。 `API` `有料`

## ボレトとCNABのライブラリ

ゲートウェイに頼らずボレトと送付ファイルを生成するため。オープンソース。

- [boleto.js](https://go.mymarketing.click/pagbr-boleto-js) - ボレトのバーコードをSVGで描画するJavaScriptライブラリ。 `オープンソース` `無料`
- [Boleto.Net](https://go.mymarketing.click/pagbr-boleto-net) - .NET向けのブラジル銀行用ボレト。 `オープンソース` `無料`
- [BoletoNetCore](https://go.mymarketing.click/pagbr-boletonetcore) - .NET Core向けのBoleto.Netバージョン。 `オープンソース` `無料`
- [BoletoPHP](https://go.mymarketing.click/pagbr-boletophp) - PHP製のオープンソースな銀行ボレトシステム。 `オープンソース` `無料`
- [brcobranca](https://go.mymarketing.click/pagbr-brcobranca) - Rubyでのボレトと送付・返送ファイル。 `オープンソース` `無料`
- [laravel-boleto](https://go.mymarketing.click/pagbr-laravel-boleto) - PHPでのボレトと送付・返送ファイル（複数銀行対応）。 `オープンソース` `無料`
- [OpenBoleto](https://go.mymarketing.click/pagbr-openboleto) - PHP에서 은행 보leto 발행 생성 라이브러리 아니라 일본어로: 「ボレート」 발행 — PHPでの銀行ボレート(boleto)発行。 `オープンソース` `無料`
