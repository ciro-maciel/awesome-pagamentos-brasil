## Aturan

Yang ditetapkan Banco Central dan Febraban.

- [Arranjos de pagamento](https://go.mymarketing.click/pagbr-arranjos-de-pagamento) - Aturan Banco Central untuk kartu, dompet, dan skema pembayaran lainnya. `resmi` `gratis`
- [Pix](https://go.mymarketing.click/pagbr-pix) - Halaman resmi Pix di Banco Central. `resmi` `gratis`
- [Pix Automático](https://go.mymarketing.click/pagbr-pix-automatico) - Mode Pix untuk tagihan berulang, dengan otorisasi awal dari pembayar. `resmi` `gratis`
- [Nova Plataforma de Boletos](https://go.mymarketing.click/pagbr-nova-plataforma-de-boletos) - Registri terpusat boleto (tagihan bank) dari Febraban. `resmi` `gratis`

## Gateway dan subakuirer

Kartu, boleto, Pix, dan langganan dalam satu API. Urut abjad.

- [Adyen](https://go.mymarketing.click/pagbr-adyen) - Platform pembayaran global, dengan kartu, Pix, dan boleto di Brasil. `API` `berbayar`
- [Asaas](https://go.mymarketing.click/pagbr-asaas) - Penagihan lewat Pix, boleto, dan kartu, dengan langganan dan split. `API` `berbayar`
- [dLocal](https://go.mymarketing.click/pagbr-dlocal) - Pembayaran di pasar berkembang, termasuk Brasil. `API` `berbayar`
- [EBANX](https://go.mymarketing.click/pagbr-ebanx) - Pembayaran lokal di Amerika Latin, untuk perusahaan dari dalam dan luar Brasil. `API` `berbayar`
- [Efí](https://go.mymarketing.click/pagbr-efi) - Eks Gerencianet: Pix, boleto, kartu, dan carnê lewat API. `API` `berbayar`
- [Iugu](https://go.mymarketing.click/pagbr-iugu) - Tagihan, langganan, dan split dengan Pix, boleto, dan kartu. `API` `berbayar`
- [Mercado Pago](https://go.mymarketing.click/pagbr-mercado-pago) - Checkout, Pix, kartu, boleto, dan langganan dari Mercado Pago. `API` `berbayar`
- [Pagar.me](https://go.mymarketing.click/pagbr-pagar-me) - Pembayaran lewat Pix, kartu, dan boleto, dengan pengulangan dan split. `API` `berbayar`
- [PagBank](https://go.mymarketing.click/pagbr-pagbank) - Pesanan dan tagihan lewat Pix, kartu, dan boleto. `API` `berbayar`
- [Stripe](https://go.mymarketing.click/pagbr-stripe) - Boleto, Pix, dan kartu di Stripe, dengan penagihan berulang lewat Stripe Billing. `API` `berbayar`
- [Vindi](https://go.mymarketing.click/pagbr-vindi) - API untuk penagihan berulang dan langganan. `API` `berbayar`
- [Zoop](https://go.mymarketing.click/pagbr-zoop) - Infrastruktur pembayaran untuk marketplace dan platform, dengan split. `API` `berbayar`

- [brcobranca](https://go.mymarketing.click/pagbr-brcobranca) - Boleto dan file remesa serta retorno dalam Ruby. `open source` `gratis`
